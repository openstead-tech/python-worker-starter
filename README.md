# Python worker and scheduled job starter

A minimal starter for [Openstead](https://openstead.tech). Use **Use this template** to create your own repository, then select it in the Openstead dashboard.

[Deploy from a starter](https://dashboard.openstead.tech/dashboard/templates) or [read the guides](https://docs.openstead.tech).

For a scheduled job, set `RUN_ONCE=1` and select the schedule in Openstead.
